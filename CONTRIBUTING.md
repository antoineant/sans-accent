# Contributing to Sans-Accent

Thank you for helping! Bug reports, words Sans-Accent gets wrong, and pull requests are all welcome.

- **A wrong accent:** open an issue with the sentence you typed, what Sans-Accent wrote, and what it
  should have written. These cases end up in the benchmark (`test/handwritten.txt`).
- **Code:** run `swift test` and the benchmark (see README) before opening a pull request.
