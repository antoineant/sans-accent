Your personal data

What the website doesn't use

The website sets no cookies and uses no trackers, no analytics and no advertising. It loads nothing from other websites, not even its fonts. That's why you see no consent banner.

What the server records

Like any web server, ours keeps a log of the pages visited: the date and time, the page requested, the browser used, the referring page and your truncated IP address. The last number of the address is replaced with a zero, which makes it anonymous.

This log is used to keep the website secure and running, and to count visits and downloads without identifying anyone. This processing is based on our legitimate interest (Article 6(1)(f) GDPR). The log is deleted automatically by rotation. If a technical error occurs, the server may also record the full IP address in an error log, deleted the same way.

The Sans-Accent app

The app reads what you type to add accents, which is why macOS asks you to grant it Accessibility access. Everything happens on your Mac. The app sends nothing, stores nothing and contains no trackers. Its code is public on GitHub, so anyone can check.

Links to other websites

The app download and the source code go through GitHub, donations through Liberapay. When you follow these links, you leave sans-accent.com, and those services apply their own privacy policies. GitHub is based in the United States, Liberapay in France.
