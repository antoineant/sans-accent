Tapez sans accents, écrivez sans fautes.

Vous écrivez en français sur un clavier QWERTY ? Sans-Accent ajoute les accents pendant que vous tapez, dans toutes vos apps.

Deux graphies possibles :
Télécharger pour Mac

Sans-Accent est gratuit et fonctionne sur macOS 14 ou version ultérieure.

Comment ça marche

Les accents arrivent tout seuls

Tapez « ecole » : le mot devient « école » dès que vous passez au suivant. Sans-Accent connaît plus de 35 000 mots et assez de grammaire pour écrire « je suis allé » ou « à cause » sans rien vous demander.

ecole→école

Vous choisissez quand le français hésite

Certains mots s'écrivent de deux façons, comme « a » et « à », ou « ou » et « où ». Une petite liste apparaît au-dessus du mot : choisissez avec ↑ ↓ puis validez avec ⏎. Si vous continuez à taper, le mot reste tel quel.

àa↑↓ ⏎

Une touche pour tout le reste

Appuyez brièvement sur ⌥ après n'importe quel mot pour voir ses autres graphies. Vous pouvez aussi désactiver Sans-Accent dans une app précise, comme votre éditeur de code.

⌥

Ce que vous tapez reste sur votre Mac

Pour ajouter les accents, Sans-Accent lit ce que vous tapez : c'est pour cela que macOS vous demande de lui accorder l'accès à l'Accessibilité. Tout se passe sur votre Mac. L'app n'envoie rien, ne garde rien et ne contient aucun traqueur.

Sans-Accent est signé par son développeur et notarisé par Apple : macOS vérifie ainsi que l'app n'a pas été modifiée depuis sa publication.

Installer Sans-Accent

  1. Téléchargez le fichier et ouvrez-le.
  2. Glissez Sans-Accent dans le dossier Applications.
  3. Lancez l'app : une fenêtre vous guide pour autoriser l'accès, puis vous propose de l'essayer tout de suite.

Questions fréquentes

Comment taper les accents français sur un clavier QWERTY Mac ?

macOS propose trois méthodes : l'appui long sur une lettre, les raccourcis avec la touche Option (⌥ E puis E pour « é ») et les remplacements de texte. Sans-Accent vous évite ces manipulations : vous tapez sans accents et l'app les ajoute toute seule. Notre guide détaille chaque méthode.

Sans-Accent fonctionne-t-il dans toutes les apps ?

Oui, dans toutes les apps où vous tapez du texte : Mail, Messages, Slack, Notion, Word, votre navigateur ou le Terminal. Il est désactivé par défaut dans les éditeurs de code, et vous pouvez le désactiver dans n'importe quelle autre app depuis son menu.

Sans-Accent envoie-t-il ce que je tape quelque part ?

Non. Sans-Accent doit lire ce que vous tapez pour ajouter les accents, d'où la demande d'accès à l'Accessibilité, mais tout se passe sur votre Mac : l'app n'envoie rien et ne garde rien. Son code est public sur GitHub : chacun peut le vérifier.

Sans-Accent est-il gratuit ?

Oui, et il le restera. Si l'app vous rend service, vous pouvez soutenir son développement sur Liberapay.

Faut-il un clavier QWERTY ?

Non. Sans-Accent est pensé pour le QWERTY, mais il aide aussi sur un clavier AZERTY, par exemple pour les majuscules accentuées comme « É » ou « À ».

Sans-Accent existe-t-il pour Windows, iPhone ou Android ?

Pas encore. Sans-Accent fonctionne sur Mac, avec macOS 14 ou une version ultérieure.
